# Origin and extraction decisions

This initial slice adapts the **libyears** repository at actual source revision
`616f14e67b25c4935fb77bf4c16acc96e7cb0226`. It is an originating case study,
not a dependency that users must install or a claim of independent adoption.
Source references below identify files in that pinned repository snapshot;
their remote publication or current URL availability was not checked.

The commissioning human names Indelegible, approves a separate experimental
repository, tables further SBOM work and supplies the four required primitives.
The author/orchestrator extracts and adapts. Fresh participant and reviewer roles
are recorded in the new synthetic witness. Earlier conversational synthesis in
libyears is credited in its Feature007 retrospective; it is interpretation
supplied through the human, distinct from authoring, execution and review.
No new conversational synthesis is represented as an independent observation.

## What came across, and what stayed behind

| Material class | Extraction decision |
| --- | --- |
| Demonstrated practice | Retain readable authority/evidence pointers, frozen review candidates, focused corrections and restart continuity. Evidence supports these mechanisms, not universal effectiveness. |
| Adopted source rule needing adaptation | Working-tree preservation, scoped grants, actor distinctions and review dispositions become Indelegible guidance in AGENTS.md and GUIDE.md. Libyears remains authoritative only for itself. |
| Exploratory proposal | Portable harness generality, optimal model routing and attention savings remain hypotheses. No runtime, Skill or distribution mechanism is selected. |
| Historical evidence | Summarize the source recovery witness separately from this repository's first use. Preserve qualifications and identifiers, not operational state. |
| Repository-specific machinery | Leave behind product/metric/ecosystem contracts, the real ledger, its 44-field schema/helper, private handoffs, telemetry, trust references and operational evidence. |

## Historical synthetic recovery witness

The source's first bounded witness, 007-0059, retained one first-response report;
a distinct evaluator judged all six recovery answers correct. Before/after packet
inventories and the dirty sentinel matched. The source first-response SHA-256 is
`20cd260212d7529fcf17e58d0e643e18313ef0e86804de24f1d059276da7674d`.
The source packet-inventory digest is
`f0b9f854dec49d795d8edcb56b59f80d5fd0db90fbfdb842a5d9f0db34a39aef`.

That child had shared filesystem access, no enforced key isolation and no complete
tool trace. Endpoint equality cannot exclude transient writes or undisclosed
reads. Capture chronology and first-response authenticity were not independently
authenticated by retained hashes. There was no established causal benefit,
execution safety, general portability, quantified attention saving or efficiency.
The case was unusually explicit; it was not an actual interrupted product task.

The [new destination check](examples/recovery/README.md) is a separate first use
of an adapted packet. It does not retroactively strengthen the source result,
establish a real second-repository task trial or isolate which guidance helped.
