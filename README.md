# Indelegible

**Human context that outlasts the conversation.**

Indelegible is an experimental, human-centered development harness made of readable
repository files. It helps a person start, direct, interrupt and resume bounded work
with an agent or another contributor. Its architectural principle is **durable
repository context over ephemeral promptext**.

Promptextual minimization reduces repeated transmission of established context.
It does not minimize tokens at the expense of readable explanations or evidence.
This first slice is guidance and a synthetic exercise, not an automated runtime,
a mature framework or evidence of broad adoption.

## Start one task

1. Read [the working rules](AGENTS.md) and [the short task guide](GUIDE.md).
2. Put one concrete user question, its grant, acceptance witness and next stop in
   a task record using the guide's small outline. Inspect the actual working state.
3. Do the next authorized action. Use [the recovery starter](STARTER.md) when
   returning or handing over; retain missing evidence rather than guessing.

Try [the fictional recovery case](examples/recovery/README.md) to see the distinction
between a prepared change and a verified result. The exercise requires only reading.
Its first destination witness and limitations are recorded with the case.

The humanic orientation preserves human understanding, agency and continuity.
Maintainerware describes work produced through this approach, not the method's
name. Contribunomics is the broader field; this repository proposes no formal
taxonomy for it.

We commit to conserving human attention and future maintainer effort; readable,
inspectable and revisable knowledge; interruption and transfer without conversational
captivity; meaningful human decisions without routine message relay; and accessible
routes to quality without a premium-model requirement. User usefulness remains
distinct from contract/test completion. Evaluate the harness's burden and retire
unnecessary ceremony. Learn from useful work with informed participation, without
manufacturing unpaid evaluation labor. Protect private operational evidence.

These are design commitments, not measured effectiveness claims. Libyears is the
originating case study. No project-wide license has been selected for Indelegible;
[provenance](PROVENANCE.md#licensing) identifies the upstream CC0 material.
